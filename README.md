# friktion-volts

**Frontend for Friktion's structured DeFi products on Solana. Covered calls, cash-secured puts, and principal-protected strategies.**

![TypeScript](https://img.shields.io/badge/TypeScript-3178C6?logo=typescript&logoColor=white)
![React](https://img.shields.io/badge/React-61DAFB?logo=react&logoColor=black)
![Solana](https://img.shields.io/badge/Solana-9945FF?logo=solana&logoColor=white)
![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)

Revival of the Friktion protocol frontend. Originally built by the Friktion team, preserved and maintained for reference and study.

## Features

- Volt strategy selection and deposit UI
- Real-time APY and performance tracking
- Wallet integration (Phantom, Solflare, etc.)
- Portfolio dashboard with position management

## Build

```bash
npm install
npm run build
```
